Personal portfolio theme of Abuobaida Mustafa.

== Description ==

The theme behind https://abuobaida.sd/. Version 1 is a classic theme built on the Underscores starter theme with a one-page portfolio homepage. Version 2, in development, rebuilds the presentation for Arabic, English and Chinese with accessible, lightweight templates. See docs/implementation in the source repository.

Recommended plugins for version 1: Advanced Custom Fields (About and Contact fields on the homepage) and Contact Form 7 (contact form).

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme, choose the theme's .zip file and click Install Now.
3. Click Activate.
